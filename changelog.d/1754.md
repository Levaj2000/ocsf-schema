### Added
#### Event Classes
- Added `ai_agent_activity` (`AI Agent Activity`) class (6009) to describe the session, prompt, permission, tool use, stop and compaction activity of autonomous AI agents.
#### Objects
- Added `ai_agent_compact_info`, `ai_agent_permission_request_info`, `ai_agent_session_end_info`, `ai_agent_session_start_info`, `ai_agent_stop_info`, `ai_agent_tool_use_info`, `ai_agent_user_prompt_submit_info`, `ai_subagent_start_info` and `ai_subagent_stop_info` objects for the activities of the `AI Agent Activity` class.
#### Dictionary Attributes
- Added `ai_tool_input` and `ai_tool_response` (`json_t`), with a deserialize-once rule for tool arguments and results that arrive as serialized JSON strings, aligned with the OpenTelemetry GenAI `gen_ai.tool.call.arguments` and `gen_ai.tool.call.result` attributes.
- Added `is_pre_occurrence` and the nine `*_info` attributes of the `AI Agent Activity` class.
